⚡ 快推导入：在 X 看到好内容，一键搬进工作台

浏览 X 帖子时，点击帖子下方的「⚡快推导入」按钮，高清视频 / 原图 + 完整文案 + #话题标签 会被一键解析并导入快推工作台，随后即可分发到全部平台。不用下载器，不用复制粘贴，不用重打标签。

实现方式：DOM 嗅探 + api.fxtwitter.com 直链解析；草稿存入 chrome.storage.local，素材持久化于 IndexedDB，零新增高危权限。

使用步骤

  1. 在 Chrome 网上应用店 安装「快推 EasyPost」。
  2. 打开工作台，编辑一次标题、正文并上传素材；或在 X 帖子下点「⚡快推导入」直接导入现成内容。
  3. 勾选要分发的平台，一键同步填充（标题字数与格式自动适配，失败自动重试）。
  4. 在各平台发布页确认后发布，再用数据追踪查看各平台表现。
